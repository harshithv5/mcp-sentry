mcp-sentry is an open-source security scanner for Model Context Protocol (MCP) servers. It connects to any MCP server, audits its tools against 14+ known attack patterns — tool poisoning, hidden instructions, prompt injection, credential leakage, path traversal, and the lethal trifecta — and produces a graded security report.
With 8,000+ MCP servers exposed on the public internet and known attack success rates above 70%, every team integrating MCP needs to audit servers before connecting them to production agents. mcp-sentry makes that audit a single command.
